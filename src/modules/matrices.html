Matrices

A matrix is a table of numbers that acts on lists of numbers. Multiplying matrices combines rows with columns, the determinant tells you whether a 2 × 2 matrix can be undone, and the inverse solves systems.

The idea

A matrix is a rectangular array of numbers; an m × n matrix has m rows and n columns. You can add matrices of the same size entry by entry and multiply by a scalar. Matrix multiplication is different: AB is defined when A has as many columns as B has rows, and each entry is a row of A dotted with a column of B. For ⟨a b; c d⟩ times ⟨e f; g h⟩ the (1, 1) entry is ae + bg, the (1, 2) entry is af + bh, the (2, 1) entry is ce + dg and the (2, 2) entry is cf + dh. In general AB ≠ BA, and the identity matrix I (1s on the diagonal) satisfies AI = IA = A.

For a 2 × 2 matrix A = ⟨a b; c d⟩ the determinant is det A = ad − bc. If det A ≠ 0, A has an inverse: A⁻¹ = (1/det A)⟨d −b; −c a⟩, and AA⁻¹ = A⁻¹A = I. If det A = 0 there is no inverse. A system a x + b y = e, c x + d y = f is AX = B with X = ⟨x, y⟩, and when A is invertible the solution is X = A⁻¹B. Geometrically det A = 0 means the two lines are parallel (or the same line).

Matrices model situations with several quantities updating together: a transition matrix T takes the current shares X of a market to the next shares TX. Applying it again and again gives T²X, T³X, … which often settle toward a steady state where TX = X.

Try this

Predict what will happen first. Then set it up and check.

  1. Use the default A = ⟨2 1; 0 3⟩ and B = ⟨1 4; −2 5⟩. What is the entry in row 1, column 2 of AB? Then switch to B · A.

    What you should see

    Row 1 of A is (2, 1) and column 2 of B is (4, 5): 2·4 + 1·5 = 13. For B · A the same entry is (1, 4)·(1, 3) = 13 as well, but other entries differ: AB = ⟨0 13; −6 15⟩ and BA = ⟨2 13; −4 13⟩.

  2. Make A the identity ⟨1 0; 0 1⟩ (a1 = 1, a2 = 0, a3 = 0, a4 = 1). What is AB?

    What you should see

    AB = B: the identity matrix leaves any matrix unchanged.

  3. In the second lab make the lines parallel: set a = 2, b = 2, c = 1, d = 1. What happens to det A and the solution?

    What you should see

    det A = 2·1 − 2·1 = 0: the lines are parallel, so there is no inverse and no single solution.

  4. Set a = 3, b = 2, c = 1, d = 1, e = 8, f = 3. Check the solution in both equations.

    What you should see

    det A = 1, A⁻¹ = ⟨1 −2; −1 3⟩ and X = ⟨2, 1⟩. Check: 3(2) + 2(1) = 8 ✓ and 2 + 1 = 3 ✓.

Worked example: multiplying 2 × 2 matrices

Let A = ⟨2 1; 0 3⟩ and B = ⟨1 4; −2 5⟩ (rows separated by semicolons). Find AB and BA, and compare.

Try it yourself first, then reveal one step at a time.

  1. Sizes. Both are 2 × 2, so AB is defined and is 2 × 2: it has A's rows and B's columns.
  2. One entry. For entry (1, 2) take row 1 of A, (2, 1), and column 2 of B, (4, 5): 2·4 + 1·5 = 13.
  3. The rest. Entry (1, 1): (2, 1)·(1, −2) = 2 − 2 = 0. Row 2 of A is (0, 3): 0·1 + 3(−2) = −6 and 0·4 + 3·5 = 15. So AB = ⟨0 13; −6 15⟩.
  4. Now BA. Row 1 of B is (1, 4): 1·2 + 4·0 = 2 and 1·1 + 4·3 = 13. Row 2 of B is (−2, 5): −2·2 + 5·0 = −4 and −2·1 + 5·3 = 13. BA = ⟨2 13; −4 13⟩, not AB: order matters. (Check with determinants: det A = 6, det B = 13, and det(AB) = 0·15 − 13(−6) = 78 = 6·13 ✓.)

Worked example 2: solve a system with the inverse

Solve 3x + 2y = 8 and x + y = 3 using a matrix inverse.

Try it yourself first, then reveal one step at a time.

  1. Write AX = B. A = ⟨3 2; 1 1⟩, X = ⟨x, y⟩, B = ⟨8, 3⟩.
  2. Determinant. det A = 3·1 − 2·1 = 1 ≠ 0, so A⁻¹ exists.
  3. Inverse. A⁻¹ = (1/1)⟨1 −2; −1 3⟩ = ⟨1 −2; −1 3⟩. Check: A A⁻¹ has first row (3·1 + 2(−1), 3(−2) + 2·3) = (1, 0) ✓.
  4. Multiply. X = A⁻¹B = ⟨1·8 + (−2)·3, −1·8 + 3·3⟩ = ⟨2, 1⟩, so x = 2, y = 1. Check: 3(2) + 2(1) = 8 ✓ and 2 + 1 = 3 ✓.

Worked example 3: market shares

Each month 80% of brand A users stay with A and 30% of brand B users switch to A. Currently 50% use A and 50% use B. Find the shares after one and two months, and the long-run share.

Try it yourself first, then reveal one step at a time.

  1. Transition matrix. T = ⟨0.8 0.3; 0.2 0.7⟩ (columns are the current brand: A stays 0.8 and leaves 0.2; B moves to A 0.3 and stays 0.7). Each column sums to 1.
  2. One month. X₁ = T⟨50, 50⟩ = ⟨0.8·50 + 0.3·50, 0.2·50 + 0.7·50⟩ = ⟨55, 45⟩.
  3. Two months. X₂ = T⟨55, 45⟩ = ⟨44 + 13.5, 11 + 31.5⟩ = ⟨57.5, 42.5⟩. The gains shrink: +5, then +2.5, then +1.25.
  4. Long run. At a steady state TX = X: 0.8x + 0.3(100 − x) = x gives 0.5x + 30 = x, so x = 60: brand A settles at 60%.

Common mistakes

  • Multiplying entry by entry: AB is not the matrix of products aᵢⱼbᵢⱼ.
  • Assuming AB = BA.
  • Using the wrong signs or positions in the inverse: swap a and d, negate b and c, divide by ad − bc.
  • Forgetting to check det A ≠ 0 before looking for an inverse.
  • Mixing up the order: X = A⁻¹B, not B A⁻¹.

Why the order of a product matters

Think of each matrix as an action: AB means "do B first, then A". Putting on socks then shoes is not the same as shoes then socks. The next module shows matrices as transformations of the plane, where that picture is literal: a rotation followed by a stretch usually differs from the stretch followed by the rotation.
