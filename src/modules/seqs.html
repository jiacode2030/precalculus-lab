Arithmetic & geometric sequences

A sequence adds the same amount each step, or multiplies by the same factor each step. These two patterns are the seeds of linear and exponential functions.

The idea

A sequence is a list of numbers a₀, a₁, a₂, … : a function whose inputs are whole numbers. In an arithmetic sequence each term is the last plus a constant common difference d: aₙ = aₙ₋₁ + d. In a geometric sequence each term is the last times a constant common ratio r: aₙ = r·aₙ₋₁.

Adding d, n times, gives an explicit formula: aₙ = a₀ + dn, a linear function of n. Multiplying by r, n times, gives aₙ = a₀·rⁿ, an exponential function of n. More generally, from any known term aₖ: aₙ = aₖ + d(n − k) or aₙ = aₖ·rⁿ⁻ᵏ.

To tell them apart from data, look at differences and ratios of consecutive terms. Constant differences mean arithmetic; constant ratios mean geometric. If neither is constant, it is neither (a quadratic, for example, has constant second differences).

Try this

Predict what will happen first. Then set it up and check.

  1. Choose add d each step with a₀ = 2 and d = 3. What do the bars show?

    What you should see

    All the bars are the same height, 3. The dots rise along a straight line: constant change means linear.

  2. Switch to multiply with r = 1.5. Do the bars still stay the same?

    What you should see

    The differences grow, but the ratios stay at 1.5. For a geometric sequence it is the ratio that is constant, not the difference.

  3. Set r = 0.5. What happens to the terms?

    What you should see

    They shrink toward 0: multiplying by a number between 0 and 1 is decay. The differences are negative and shrinking in size.

  4. In the second lab choose aₙ = 2·aₙ₋₁ and set n = 10. Which is quicker: building up, or jumping?

    What you should see

    Jumping: a₁₀ = 1·2¹⁰ = 1024 takes one calculation, while the chain takes ten. That is why explicit formulas matter.

Worked example: seats in a theater

The first row of a theater has 20 seats and each row has 3 more seats than the row in front of it. Write a formula for the number of seats in row n, and find the first row with more than 100 seats.

Try it yourself first, then reveal one step at a time.

  1. Type. The same amount is added each row, so the sequence is arithmetic with first term 20 (row 1) and d = 3.
  2. Formula. From row 1: a(n) = 20 + 3(n − 1) = 3n + 17. Check: a(2) = 23 ✓.
  3. Solve. 3n + 17 > 100 gives 3n > 83, so n > 27.67.
  4. Answer. The first whole row number is 28. Check: a(27) = 98 and a(28) = 101.

Worked example 2: a video catches on

A video has 500 views on day 0, and each day it gets 1.2 times as many total views as the day before. Find the views on day 10 and the first day with more than 2000 views.

Try it yourself first, then reveal one step at a time.

  1. Type. Each day is multiplied by 1.2, so the sequence is geometric with a₀ = 500 and r = 1.2: vₙ = 500(1.2)ⁿ.
  2. Day 10. v₁₀ = 500(1.2)¹⁰ = 500(6.1917…) ≈ 3096 views.
  3. Day with more than 2000. Try values: v₇ = 500(3.5832) ≈ 1792 and v₈ = 500(4.2998) ≈ 2150.
  4. Answer. The first day above 2000 is day 8. (Later, logarithms will solve 500(1.2)ⁿ = 2000 directly: n ≈ 7.6.)

Common mistakes

  • Calling a sequence arithmetic because the terms increase. Check that the differences are equal.
  • Using aₙ = a₀ + d·n with n starting at 1 when the first given term is a₁: use the term you know.
  • Dividing in the wrong order for the ratio: r = aₙ / aₙ₋₁, the later over the earlier.
  • Confusing the common difference with the common ratio.

Sequences are functions

A sequence is a function whose inputs are integers. Arithmetic sequences are the integer points of a line, and geometric sequences are the integer points of an exponential curve a·bˣ. The next modules turn these dots into continuous graphs, and the same two ideas, constant change versus constant factor, drive everything in Unit 2.
