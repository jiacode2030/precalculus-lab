Linear vs quadratic change

Linear functions change by the same amount every step. Quadratics change by an amount that itself changes steadily.

The idea

Take equal steps in the input. For a linear function the output changes by the same amount each step: the average rate of change is constant, and it is the slope. Equal inputs steps, equal output steps.

For a quadratic function the output changes are not equal, but they change by the same amount each time: the second differences are constant. Over consecutive equal-length intervals, the average rates of change form a linear pattern. For f(x) = ax² + bx + c and steps of size h, the second difference is 2ah².

That links rates to shape. If the average rates are increasing, the graph bends up (concave up, a > 0); if they are decreasing, it bends down (concave down, a < 0). A line has no bend at all.

Try this

Predict what will happen first. Then set it up and check.

  1. Set a = 0. What do the bars look like, and why?

    What you should see

    All the same height: with a = 0 the function is linear, f(x) = 2x + 1, and every step of 1 in x adds exactly 2.

  2. Set a = 0.5, b = −1, h = 1. How much does each bar grow by?

    What you should see

    By 1 each time: the first differences are −0.5, 0.5, 1.5, 2.5, …, and the second differences are all 2ah² = 2(0.5)(1) = 1.

  3. Keep a = 0.5 and change the step to h = 2. What happens to the second difference?

    What you should see

    It becomes 2(0.5)(2²) = 4: four times as big. It is still constant, so the test still says quadratic.

  4. In the second lab choose Dropped stone. What is the pattern in the average rates?

    What you should see

    They rise by 9.8 m/s every second: the rates lie on a straight line with slope 9.8, the acceleration of gravity. Constant change in the rate is the signature of a quadratic.

  5. Choose Taxi fare. What does the bottom graph show?

    What you should see

    A flat line: every kilometer costs the same, so the rate never changes. Linear.

Worked example 2: a dropped stone

A stone dropped from a cliff has fallen d(t) = 4.9t² meters after t seconds. Find the average speed in each of the first four seconds. What pattern do you see?

Try it yourself first, then reveal one step at a time.

  1. Distances. d(0) = 0, d(1) = 4.9, d(2) = 19.6, d(3) = 44.1, d(4) = 78.4 m.
  2. Average speeds. 4.9, 14.7, 24.5 and 34.3 m/s on [0, 1], [1, 2], [2, 3], [3, 4].
  3. Pattern. Each average speed is 9.8 m/s more than the one before. The rates change at a constant rate, which is exactly what makes d quadratic (second difference 2ah² = 2(4.9)(1) = 9.8).
  4. Meaning. 9.8 m/s per second is the acceleration of gravity. The rates are increasing, so the graph of d is concave up.

Common mistakes

  • Testing differences when the x-values are not equally spaced.
  • Stopping at the first differences: unequal first differences rule out linear but do not prove quadratic.
  • Using the second difference as a: with step 1 it is 2a, not a.
  • Calling a function concave up because it is increasing.

Where 2ah² comes from

For f(x) = ax² + bx + c, the change over [x, x + h] is f(x + h) − f(x) = 2ahx + ah² + bh. That is a linear function of x with slope 2ah, so moving x forward by h changes it by 2ah · h = 2ah². The b and c terms only shift the first differences; they never affect the second ones.
