Inverse functions

An inverse function undoes the original: inputs and outputs trade places, and the graph flips over the line y = x.

The idea

If f takes a to b, its inverse f⁻¹ takes b back to a. This only works if each output comes from exactly one input: f must be one-to-one. On a graph, that is the horizontal line test: no horizontal line meets the graph twice. The inverse swaps domain and range: the domain of f⁻¹ is the range of f, and the range of f⁻¹ is the domain of f. Note that f⁻¹(x) means the inverse, not 1/f(x).

The two functions undo each other: f(f⁻¹(x)) = x and f⁻¹(f(x)) = x. Geometrically, if (a, b) is on the graph of f then (b, a) is on the graph of f⁻¹, so the two graphs are mirror images across the line y = x.

To find a formula: write y = f(x), swap x and y, and solve for y. For f(x) = 2x + 1: x = 2y + 1 gives y = (x − 1)/2. A function like x² is not one-to-one, but if you restrict the domain to x ≥ 0 it becomes one-to-one, and its inverse is √x. The choice of restriction decides which inverse you get.

Horizontal line test

A function has an inverse exactly when every horizontal line meets its graph at most once.

1. f(x) = x³. Does f have an inverse function? Imagine a horizontal line sweeping up the graph.

Every horizontal line crosses the graph at most once: each output comes from exactly one input, so f has an inverse.

2. f(x) = x². Does f have an inverse function? Imagine a horizontal line sweeping up the graph.

The horizontal line y = 3 crosses the graph 2 times: two inputs give the same output, so f has no inverse on this whole domain.

3. f(x) = 2ˣ. Does f have an inverse function? Imagine a horizontal line sweeping up the graph.

Every horizontal line crosses the graph at most once: each output comes from exactly one input, so f has an inverse.

4. f(x) = |x|. Does f have an inverse function? Imagine a horizontal line sweeping up the graph.

The horizontal line y = 2 crosses the graph 2 times: two inputs give the same output, so f has no inverse on this whole domain.

5. f(x) = x³ − 3x. Does f have an inverse function? Imagine a horizontal line sweeping up the graph.

The horizontal line y = 1 crosses the graph 3 times: two inputs give the same output, so f has no inverse on this whole domain.

6. f(x) = 0.5x + 1. Does f have an inverse function? Imagine a horizontal line sweeping up the graph.

Every horizontal line crosses the graph at most once: each output comes from exactly one input, so f has an inverse.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose 2x + 1. Move the point on f. Where does its mirror image lie?

    What you should see

    On the green graph, with the coordinates swapped: (1, 3) on f becomes (3, 1) on f⁻¹. They are mirror images over the dashed line.

  2. Choose x² for x ≥ 0. What is the inverse?

    What you should see

    The square root: (2, 4) becomes (4, 2). The restriction x ≥ 0 is what makes an inverse possible.

  3. Choose 2ˣ. The inverse climbs very slowly. Why?

    What you should see

    Because 2ˣ climbs very fast: reflecting a steep graph gives a flat one. This inverse is a logarithm, coming in the next module.

  4. In the second lab choose 12/x and any input. What do you notice?

    What you should see

    f(3) = 4 and f⁻¹(4) = 3, and f⁻¹(x) = 12/x too. This function is its own inverse: its graph is symmetric about y = x.

Worked example: temperature conversion

A thermometer converts Celsius to Fahrenheit with F = 1.8C + 32. Find the inverse formula and convert a body temperature of 98.6°F to Celsius.

Try it yourself first, then reveal one step at a time.

  1. Write y = f(x). F = 1.8C + 32, with C as the input.
  2. Swap and solve. Solve for C: F − 32 = 1.8C, so C = (F − 32)/1.8. This is the inverse: it takes Fahrenheit in and gives Celsius out.
  3. Evaluate. C = (98.6 − 32)/1.8 = 66.6/1.8 = 37°C.
  4. Check. f(37) = 1.8(37) + 32 = 66.6 + 32 = 98.6 ✓. The inverse undid f.

Worked example 2: radius from area

The area of a circle is A(r) = πr² for r ≥ 0. Find the inverse and the radius of a circle with area 50 cm².

Try it yourself first, then reveal one step at a time.

  1. One-to-one? On all real numbers π r² is not (r and −r give the same area), but radius cannot be negative: on r ≥ 0 it is one-to-one.
  2. Solve. A = πr² gives r² = A/π, so r = √(A/π) (positive root only).
  3. Evaluate. r(50) = √(50/π) = √15.915… ≈ 3.99 cm.
  4. Check. π(3.99)² = π(15.92) ≈ 50 ✓.

Common mistakes

  • Reading f⁻¹(x) as 1/f(x).
  • Swapping x and y but forgetting to solve for y.
  • Using an inverse on a function that is not one-to-one without restricting the domain.
  • Reflecting over the x-axis or y-axis instead of the line y = x.

Inverse as a way to solve equations

Solving f(x) = k means finding the input that gives output k, which is f⁻¹(k). Every time you "undo" an operation to solve an equation, you apply an inverse function: subtract to undo adding, divide to undo multiplying, take the square root to undo squaring (on the right branch).
