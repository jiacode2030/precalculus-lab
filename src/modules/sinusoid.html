Sinusoidal transformations

Every sine wave is the same wave, stretched and shifted. Four numbers say how: amplitude, period, phase shift and midline.

The idea

A sinusoidal function is any transformation of sine or cosine: f(θ) = a sin(b(θ + c)) + d. Each parameter does one job. a stretches vertically: the amplitude is |a|. d moves the wave up: the midline is y = d. b squeezes horizontally: the period is 2π/|b|. c slides it sideways: the phase shift is −c (so θ + π/4 moves the graph left by π/4).

Cosine is a sine wave shifted left by π/2: cos θ = sin(θ + π/2). So a sinusoid can always be written either way; pick the one whose starting point is easiest (cosine starts at a maximum, sine starts on the midline going up).

Read the parameters straight off a graph: midline = (max + min)/2, amplitude = (max − min)/2, period = the distance between two neighboring maxima.

Try this

Predict what will happen first. Then set it up and check.

  1. Set a = 2, then a = −2. What does a negative a do?

    What you should see

    The amplitude is still 2, but the wave is flipped over its midline: it now starts on the midline going down. Amplitude is |a|.

  2. Set b = 2 and then b = 0.5 (keep a = 1). How long is one cycle each time?

    What you should see

    Period = 2π/b: π ≈ 3.14 for b = 2 (twice as many waves) and 4π ≈ 12.57 for b = 0.5 (half as many). Bigger b squeezes the wave.

  3. Set b = 2 and c = 0.785 (about π/4). Is the shift π/4 or π/8? Read the start of the cycle.

    What you should see

    π/4 to the left. The form b(θ + c) factors b out first, so the shift is −c = −π/4. Had it been written sin(2θ + π/4) = sin(2(θ + π/8)), the shift would be π/8.

  4. Choose cos with c = 0, then sin with c = 1.57. Compare the two graphs.

    What you should see

    They match (up to rounding of π/2): sin(θ + π/2) = cos θ. A cosine is a sine that starts half a hump early.

  5. In the second lab, drag the minimum farther right. What happens to the period?

    What you should see

    The period is twice the horizontal distance from a maximum to the next minimum. Doubling that distance doubles the period and halves b = 2π/period.

Worked example

Find the amplitude, period, phase shift, midline and range of f(θ) = 3 sin(2(θ − π/4)) + 1, then sketch one cycle.

Try it yourself first, then reveal one step at a time.

  1. Midline. d = 1, so the midline is y = 1.
  2. Amplitude. a = 3, so the wave rises 3 above and falls 3 below the midline: range [−2, 4].
  3. Period. b = 2, so the period is 2π/2 = π.
  4. Phase shift. θ − π/4 means c = −π/4: the cycle starts π/4 to the right, at θ = π/4, on the midline going up.
  5. Key points. A quarter period later (θ = π/4 + π/4 = π/2) it reaches the max 4; at θ = 3π/4 it is back on the midline; at θ = π it hits the min −2; at 5π/4 the cycle ends.

Worked example 2: the voltage in a wall outlet

The voltage of a US wall outlet is modeled by V(t) = 170 sin(120πt) volts, with t in seconds. (a) Find the amplitude, period and frequency. (b) When is the voltage first 85 V?

Try it yourself first, then reveal one step at a time.

  1. Amplitude. a = 170: the voltage swings between −170 V and 170 V.
  2. Period and frequency. b = 120π, so the period is 2π/(120π) = 1/60 s and the frequency is 60 cycles per second (60 Hz).
  3. (b) Solve 170 sin(120πt) = 85. sin(120πt) = 1/2. The first positive angle with sine 1/2 is π/6, so 120πt = π/6 and t = 1/720 s ≈ 0.00139 s.
  4. Why "120 volts"? The label on an outlet is the root-mean-square value, peak ÷ √2: 170/√2 ≈ 120 V. The peak really is about 170 V (120√2 ≈ 169.7).

Common mistakes

  • Reading the period as b instead of 2π/b.
  • Taking the phase shift from sin(2θ + π/2) as π/2. Factor first: sin(2(θ + π/4)), so the shift is π/4 to the left.
  • Getting the shift direction backwards: θ − h moves right by h, θ + h moves left.
  • Calling a negative a a negative amplitude. Amplitude is |a|; the sign flips the wave.
  • Forgetting the midline when finding max and min: max = d + |a|, min = d − |a|.

Sine or cosine?

Any sinusoid can be written with either. Cosine begins its cycle at a maximum, sine on the midline going up, so choose the one that matches an easy point on your graph or in your context. A Ferris wheel that starts at the bottom, for instance, is −cos: it starts at a minimum.
