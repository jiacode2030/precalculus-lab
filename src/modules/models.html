Building function models

Choose the kind of function that fits the situation, say what you are assuming, and use the model with care.

The idea

A function model is a function that describes a real situation. To select one, look at the data and the context. Constant first differences: linear. Constant second differences: quadratic. Outputs that level off toward a value (like cost per unit): rational. A graph that changes behavior at a known point: piecewise. A shape that rises, falls and rises again: cubic or higher.

Every model carries assumptions: that growth stays the same, that the shape continues, that no other factors matter. State them, check them against the data, and say where the model should not be trusted, especially outside the range of the data (extrapolation). A residual is data minus model: random residuals say the model fits; a pattern in the residuals says it does not.

To construct a model: choose a type, find its parameters (from points, differences, a regression, or the context), state the domain, and use it to answer the question asked, with units. A piecewise function uses different formulas on different intervals, such as a bill with tiered rates; check what happens at the breakpoints.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose Stopping distance with a linear model. What pattern do the residuals show?

    What you should see

    A U-shape: positive at both ends, negative in the middle. A pattern in the residuals means a line is the wrong kind of function.

  2. Switch to quadratic. What happens to the residuals?

    What you should see

    They shrink to almost nothing and show no pattern: the quadratic fits.

  3. Choose Cost per unit. Which model type fits best?

    What you should see

    The a/x + b model, with b near the per-unit cost. Quadratic and cubic fits can match the points but go wrong outside the data.

  4. In the second lab, set both rates to 0.12. What happens at the breakpoint?

    What you should see

    The kink disappears: it is a single line. A piecewise model needs different rates to be a genuinely different model.

  5. Move the breakpoint to 300. Does the bill at 800 kWh go up or down?

    What you should see

    Up: more of the usage is charged at the higher rate, so the 800 kWh bill rises.

Worked example: choosing a model from a table

A driver tests the stopping distance d (in feet) at several speeds v (in mph). Choose a model, find its formula, and predict d at 70 mph. Say what you are assuming.

Stopping distance
v (mph)2030405060
d (ft)4482.5132192.5264

Try it yourself first, then reveal one step at a time.

  1. First differences (step 10): 38.5, 49.5, 60.5, 71.5. Not constant, so not linear.
  2. Second differences: 11, 11, 11. Constant: choose a quadratic. With step 10, 2a(10)² = 11, so a = 0.055.
  3. The rest. d = 0.055v² + bv + c. Using d(20) = 44 and d(30) = 82.5: 22 + 20b + c = 44 and 49.5 + 30b + c = 82.5, so b = 1.1 and c = 0. d = 0.055v² + 1.1v.
  4. Predict. d(70) = 0.055(4900) + 1.1(70) = 269.5 + 77 = 346.5 ft. This assumes the same road, tires and driver as in the test, and speeds beyond the data (extrapolation).

Worked example 2: a tiered electricity bill

An electric company charges a $10 fee plus $0.12 per kWh for the first 500 kWh, and $0.18 per kWh for each kWh above 500. Write the bill C(x) as a piecewise function and find the bill for 800 kWh.

Try it yourself first, then reveal one step at a time.

  1. First piece (0 ≤ x ≤ 500): C(x) = 10 + 0.12x. At 500 kWh: 10 + 60 = $70.
  2. Second piece (x > 500): start from $70 and add $0.18 for each kWh above 500: C(x) = 70 + 0.18(x − 500).
  3. Piecewise form. C(x) = 10 + 0.12x for 0 ≤ x ≤ 500; C(x) = 70 + 0.18(x − 500) for x > 500.
  4. 800 kWh. C(800) = 70 + 0.18(300) = 70 + 54 = $124. The pieces meet at (500, 70), so the bill has no jump.

Common mistakes

  • Choosing a model by its R² or how close it looks inside the data, without thinking about the context or what happens outside.
  • Extrapolating far beyond the data and trusting it.
  • Writing a piecewise function with pieces that do not meet when the story says they do.
  • Forgetting units, or the domain on which the model makes sense.

No model is right; some are useful

A model is a simplified description. A quadratic for stopping distance is right for the physics (braking distance grows with the square of speed), plus a term for reaction time. A cubic could fit the same five points but has no physical reason to. Good modeling joins the data to the story.
