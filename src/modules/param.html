Parametric functions

Give x and y each their own clock. As t ticks, the point (x(t), y(t)) moves along a path, with a direction and a speed built in.

The idea

A parametric function gives both coordinates as functions of a third variable, the parameter t (often time): (x(t), y(t)). As t increases, the point traces a path in the plane, in a definite direction. The path alone does not show when the point was where; the parametric function does.

Read it as three linked pictures: the graph of x(t), the graph of y(t), and the path. When x(t) is increasing the point moves right; when y(t) is increasing it moves up. A line segment from (x₀, y₀) to (x₁, y₁) is x = x₀ + (x₁ − x₀)t, y = y₀ + (y₁ − y₀)t for 0 ≤ t ≤ 1. A circle of radius r centered at (h, k) is x = h + r cos t, y = k + r sin t, counterclockwise.

Sometimes you can eliminate the parameter: solve one equation for t and substitute into the other to get an equation in x and y. That gives the shape of the path, but loses the direction and the timing.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose Circle and press Play. Which way does the point go, and where is it at t = π/2?

    What you should see

    Counterclockwise, starting at (3, 0). At t = π/2 it is at (3 cos π/2, 3 sin π/2) = (0, 3), the top. x(t) is a cosine and y(t) a sine.

  2. With the circle, find a time when x(t) is decreasing and y(t) is increasing. Where is the point?

    What you should see

    For 0 < t < π/2: moving left (x decreasing) and up (y increasing), so the point is in quadrant I heading toward the top.

  3. Choose Kicked ball. Watch the dots on the x(t) graph and on the path. Why are they evenly spaced across but not up?

    What you should see

    x(t) = 18t is linear: the ball covers 18 m sideways every second. y(t) is a downward parabola: fast rise, slowing at the top, then falling faster.

  4. Choose Figure-eight. The path crosses itself at the origin. Is the point ever there twice at the same time?

    What you should see

    No: it passes through (0, 0) at t = 0 and again at t = π, at different times and heading in different directions. A path can cross itself; a parametric function just visits the same place twice.

  5. In the second lab choose Stop and go back. Where does x(t) level off, and what does the point do there?

    What you should see

    Where both graphs level off together, the point stops; where they then reverse, it retraces its path backward. The path looks like a plain segment, but the motion goes out, pauses and comes back.

Worked example

Parametrize the segment from A(1, 2) to B(7, −1) with 0 ≤ t ≤ 1, find the point at t = 1/3, then parametrize the trip from B back to A taking 0 ≤ t ≤ 2.

Try it yourself first, then reveal one step at a time.

  1. Endpoints. Start A(1, 2), end B(7, −1). The change is Δx = 6 and Δy = −3.
  2. Start plus a fraction of the change. x = 1 + 6t, y = 2 − 3t, 0 ≤ t ≤ 1. At t = 0 it is A, at t = 1 it is B.
  3. t = 1/3. x = 1 + 2 = 3, y = 2 − 1 = 1: the point (3, 1), one third of the way from A to B.
  4. Reverse in 2 units of time. Start at B and cover the change (−6, 3) at half the rate: x = 7 − 3t, y = −1 + 1.5t, 0 ≤ t ≤ 2. Same path, opposite direction, different timing.

Worked example 2: a kicked soccer ball

A ball is kicked from 1 m above the ground. Its position after t seconds is x(t) = 18t, y(t) = 1 + 12t − 4.9t² (meters). (a) When is the ball highest, and how high? (b) When and where does it land? (c) Eliminate t to find the shape of the path.

Try it yourself first, then reveal one step at a time.

  1. Read each coordinate. x(t) = 18t: 18 m per second sideways, steadily. y(t) is a quadratic opening down: up, then down.
  2. (a) The vertex of y(t) is at t = −12/(2 · (−4.9)) = 12/9.8 ≈ 1.224 s. Then y = 1 + 144/19.6 ≈ 8.35 m, at x ≈ 22.0 m.
  3. (b) Lands when y = 0: 4.9t² − 12t − 1 = 0, so t = (12 + √163.6)/9.8 ≈ 2.530 s (the other root is negative). Then x = 18(2.530) ≈ 45.5 m.
  4. (c) t = x/18, so y = 1 + 12(x/18) − 4.9(x/18)² = 1 + (2/3)x − 0.01512x²: a parabola. The equation gives the shape, but not when the ball is where.

Common mistakes

  • Treating the path as the graph of a function of x: a path can loop, cross itself or go straight up.
  • Ignoring direction: x = cos t, y = sin t and x = sin t, y = cos t trace the same circle in opposite directions.
  • Plugging x into y(t): find t first, then use it in both coordinates.
  • Forgetting the t-interval: it decides where the path starts, stops, and how many times it is traced.
  • Assuming equal steps in t give equal distances on the path.

One path, many parametrizations

The path x² + y² = 1 is the circle, but (cos t, sin t), (cos 2t, sin 2t), (sin t, cos t) and (cos t, −sin t) are four different motions on it: different speeds and directions. Planar motion problems care about the motion, so the parametric function carries more information than the path.
