Zeros & complex zeros

Every zero of a polynomial is a factor. Count them with multiplicity, include the complex ones, and a degree-n polynomial has exactly n.

The idea

If f(a) = 0 then (x − a) is a factor of f, and a is a zero (an x-intercept when a is real). If the factor appears k times, a has multiplicity k. At a zero of odd multiplicity the graph crosses the x-axis (the sign changes); at even multiplicity it touches and turns back (no sign change). Higher multiplicity flattens the graph near the zero.

A polynomial of degree n has exactly n complex zeros, counting multiplicity (the Fundamental Theorem of Algebra). Some can be non-real, like 1 + i. If the coefficients are real, non-real zeros come in conjugate pairs a + bi and a − bi, so a real cubic always has at least one real zero.

Factors give you the sign of f between zeros, which solves polynomial inequalities. Symmetry is another shortcut: f is even if f(−x) = f(x) (mirror image in the y-axis, like x⁴ − x²) and odd if f(−x) = −f(x) (symmetric about the origin, like x³ − 4x).

Worked example: from zeros to a formula

A degree-4 polynomial f with real coefficients has a zero of multiplicity 2 at x = 2, and 1 + i is also a zero. If f(0) = 8, find f(x).

Try it yourself first, then reveal one step at a time.

  1. Count the zeros. Degree 4 means 4 zeros with multiplicity: 2, 2, and 1 + i. The fourth must be the conjugate 1 − i.
  2. Pair the conjugates. (x − (1 + i))(x − (1 − i)) = (x − 1)² − i² = x² − 2x + 2, which has real coefficients.
  3. Write the form. f(x) = a(x − 2)²(x² − 2x + 2). Then f(0) = a(4)(2) = 8a = 8, so a = 1.
  4. Answer. f(x) = (x − 2)²(x² − 2x + 2) = x⁴ − 6x³ + 14x² − 16x + 8. Only one x-intercept, at 2, where the graph touches.

Worked example 2: when is the business profitable?

A company's monthly profit is P(q) = −q³ + 12q² − 20q thousand dollars when it sells q thousand units. For which q is the profit positive?

Try it yourself first, then reveal one step at a time.

  1. Factor. P(q) = −q(q² − 12q + 20) = −q(q − 2)(q − 10). Zeros: 0, 2, 10, each multiplicity 1, so the sign changes at each.
  2. Test the sign. For 0 < q < 2, try q = 1: −1(−1)(−9) = −9 < 0. For 2 < q < 10, try q = 5: −5(3)(−5) = 75 > 0. For q > 10, try q = 11: −11(9)(1) = −99 < 0.
  3. Answer. P(q) > 0 for 2 < q < 10: between 2,000 and 10,000 units.
  4. Meaning. Below 2,000 units fixed costs eat the profit; above 10,000 the model says extra production costs more than it earns. The zeros are the break-even points.

Common mistakes

  • Forgetting the conjugate: if 3 − 2i is a zero of a real polynomial, so is 3 + 2i.
  • Counting x-intercepts as the number of zeros: non-real zeros have no x-intercept.
  • Saying a graph crosses at a squared factor.
  • Writing the factor for the zero −4 as (x − 4) instead of (x + 4).

Why conjugates come in pairs

If f has real coefficients and f(a + bi) = 0, take the complex conjugate of the whole equation. Conjugating a sum or product conjugates each piece, and the real coefficients stay the same, so f(a − bi) = 0 too. Multiplying the pair gives x² − 2ax + (a² + b²), a quadratic with real coefficients and no real zeros.
