Linear transformations

A 2 × 2 matrix is a function that moves every point of the plane. Its columns say where the basis vectors land, its determinant says how areas change, and multiplying matrices composes the moves.

The idea

A linear transformation sends a point (x, y) to a new point by ⟨x, y⟩ → ⟨ax + by, cx + dy⟩, which is the matrix product ⟨a b; c d⟩⟨x, y⟩. Grid lines stay straight and parallel, and the origin stays fixed. To find the matrix of a transformation, ask where the basis vectors î = ⟨1, 0⟩ and ĵ = ⟨0, 1⟩ go: their images are the columns of the matrix. A rotation by θ counterclockwise is ⟨cos θ −sin θ; sin θ cos θ⟩; a stretch by factors p and q is ⟨p 0; 0 q⟩; a reflection over the x-axis is ⟨1 0; 0 −1⟩; a shear is ⟨1 k; 0 1⟩.

The determinant measures area: the unit square becomes a parallelogram of area |ad − bc|, so every area is multiplied by |det|. A negative determinant means orientation is flipped (a reflection is involved). If det = 0, the whole plane collapses onto a line or a point and cannot be undone. If det ≠ 0 the inverse matrix is the transformation that undoes the move.

Composition: doing P first and then Q is the matrix product QP (the first transformation is on the right, next to the input). Since matrix multiplication is not commutative, the order of moves matters: a rotation followed by a stretch usually differs from the stretch followed by the rotation.

Worked example: build a rotation matrix

Find the matrix of the transformation that rotates the plane 90° counterclockwise about the origin, and use it to find the image of P = (3, 2).

Try it yourself first, then reveal one step at a time.

  1. Follow the basis vectors. A 90° counterclockwise rotation turns î = ⟨1, 0⟩ into ⟨0, 1⟩ and ĵ = ⟨0, 1⟩ into ⟨−1, 0⟩.
  2. Columns of the matrix. M = ⟨0 −1; 1 0⟩ (first column ⟨0, 1⟩, second column ⟨−1, 0⟩). This matches ⟨cos 90° −sin 90°; sin 90° cos 90°⟩.
  3. Apply to P. M⟨3, 2⟩ = ⟨0·3 + (−1)·2, 1·3 + 0·2⟩ = ⟨−2, 3⟩.
  4. Check. The distance from the origin is unchanged: √(3² + 2²) = √13 and √((−2)² + 3²) = √13 ✓, and det M = 0·0 − (−1)(1) = 1, so areas are preserved.

Worked example 2: composing a shear and a stretch

S = ⟨1 2; 0 1⟩ shears the plane and D = ⟨2 0; 0 1⟩ doubles x. Find the matrix of "S first, then D" and of "D first, then S". Apply each to P = (1, 1).

Try it yourself first, then reveal one step at a time.

  1. Order. "S first, then D" is the product DS (the first move is written on the right).
  2. DS. ⟨2 0; 0 1⟩⟨1 2; 0 1⟩ = ⟨2·1 + 0·0, 2·2 + 0·1; 0·1 + 1·0, 0·2 + 1·1⟩ = ⟨2 4; 0 1⟩. And SD = ⟨1 2; 0 1⟩⟨2 0; 0 1⟩ = ⟨2 2; 0 1⟩.
  3. Apply to P = (1, 1). DS⟨1, 1⟩ = ⟨2 + 4, 1⟩ = ⟨6, 1⟩. Check by steps: S sends (1, 1) to (3, 1), then D to (6, 1) ✓. SD⟨1, 1⟩ = ⟨2 + 2, 1⟩ = ⟨4, 1⟩.
  4. Compare. DS ≠ SD, so the order matters. Their determinants agree: det DS = det SD = 2 = (det D)(det S) = 2·1.

Worked example 3: the determinant as area

M = ⟨3 1; 1 2⟩. Find the area of the image of the unit square, and find the inverse of M.

Try it yourself first, then reveal one step at a time.

  1. Images of î and ĵ. The columns: î → ⟨3, 1⟩ and ĵ → ⟨1, 2⟩. The unit square becomes the parallelogram with vertices (0, 0), (3, 1), (4, 3), (1, 2).
  2. Area. det M = 3·2 − 1·1 = 5, so the area is 5 times the original: 5.
  3. Inverse. M⁻¹ = (1/5)⟨2 −1; −1 3⟩ = ⟨0.4 −0.2; −0.2 0.6⟩. It maps the parallelogram back to the unit square and scales areas by 1/5.
  4. Check. M M⁻¹: first row (3, 1)·(0.4, −0.2) = 1.2 − 0.2 = 1 and (3, 1)·(−0.2, 0.6) = −0.6 + 0.6 = 0, as the identity requires.

Common mistakes

  • Writing the images of î and ĵ as the rows of the matrix: they are the columns.
  • Composing in the wrong order: "P first, then Q" is QP, not PQ.
  • Forgetting that a determinant of 0 means the plane collapses and there is no inverse.
  • Thinking a negative determinant means a negative area: it means orientation flips; the area scale is |det|.
  • Assuming every transformation fixes points other than the origin: only the origin is always fixed.

Why every linear map is determined by two vectors

Because the transformation keeps grid lines straight and parallel, the image of any point ⟨x, y⟩ = x î + y ĵ is x times the image of î plus y times the image of ĵ. So two columns are all you need to know. This is why matrices are so efficient for computer graphics: every rotation, resize and shear of an image is a single 2 × 2 matrix applied to every pixel.
