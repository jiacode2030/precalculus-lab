The tangent function

Tangent is the slope of the radius. It repeats every half turn and shoots off to infinity whenever the radius stands straight up.

The idea

On the unit circle the radius to the angle θ runs from (0, 0) to (cos θ, sin θ), so its slope is tan θ = sin θ / cos θ. Extend the radius until it hits the vertical line x = 1: it hits at height tan θ. That segment is where the name "tangent" comes from.

When the radius is vertical (θ = π/2, 3π/2, ...) cos θ = 0 and the slope is undefined: the graph has a vertical asymptote. Between two asymptotes the slope runs through every real number, from −∞ to ∞, and it is increasing the whole way.

Turning the radius by half a turn (π) points it the opposite way, but a line through the origin has the same slope in both directions, so tan(θ + π) = tan θ: the period is π, not 2π. Transformations work as for sine: f(θ) = a tan(b(θ + c)) + d has period π/|b|.

Try this

Predict what will happen first. Then set it up and check.

  1. Drag θ from 0 toward π/2 (1.571). What happens to the orange tangent segment and to tan θ?

    What you should see

    The radius gets steeper, the segment on x = 1 climbs faster and faster, and tan θ grows without bound: tan 1.3 ≈ 3.6, tan 1.5 ≈ 14.1. At π/2 it is undefined.

  2. Go just past π/2, to about 1.65. Where is the tangent segment now?

    What you should see

    Far below the axis: tan 1.65 ≈ −12.6. The radius now slopes down to the right when extended backward through the origin to x = 1. The graph jumps from +∞ to −∞ across the asymptote.

  3. Set θ = 0.5, then θ = 0.5 + π ≈ 3.64. Compare the values.

    What you should see

    Both are ≈ 0.546. The two radii point opposite ways along the same line through the origin, so they have the same slope: the period of tangent is π.

  4. In the second lab set b = 2. Where are the asymptotes now, and what is the period?

    What you should see

    tan(2θ) is undefined when 2θ = π/2 + kπ, so θ = π/4 + kπ/2: every π/2. The period is π/2, half the parent period.

  5. Set a = −1 (b = 1). Is the graph still increasing between asymptotes?

    What you should see

    No: a negative a flips it, so each branch is decreasing. The asymptotes and the period do not change.

Worked example

For g(θ) = 3 tan(θ/2) + 1, find the period and the vertical asymptotes, and evaluate g(π/2) and g(−π/2).

Try it yourself first, then reveal one step at a time.

  1. Asymptotes. tan(θ/2) is undefined when θ/2 = π/2 + kπ, so θ = π + 2kπ: …, −π, π, 3π, …
  2. Period. b = 1/2, so the period is π ÷ (1/2) = 2π: the distance between neighboring asymptotes.
  3. Center of a branch. At θ = 0, tan 0 = 0 and g(0) = 1. Each branch passes through its center on the line y = 1 (the d value).
  4. Values. g(π/2) = 3 tan(π/4) + 1 = 3 + 1 = 4, and g(−π/2) = 3 tan(−π/4) + 1 = −3 + 1 = −2. Since a = 3 > 0, each branch increases from −∞ to ∞.

Worked example 2: tracking a rocket

A camera on the ground 50 m from a launch pad tilts up to follow a rocket rising straight up. When the camera's angle of elevation is θ, the rocket's height is h = 50 tan θ meters. (a) Find h at θ = π/6, π/4 and π/3. (b) Find the average rate of change of h on [π/6, π/4] and on [π/4, π/3]. (c) What happens as θ approaches π/2?

Try it yourself first, then reveal one step at a time.

  1. Model. In the right triangle, the side opposite θ is the height h and the side adjacent is 50 m, so tan θ = h/50 and h = 50 tan θ.
  2. (a) h(π/6) = 50 · √3/3 ≈ 28.87 m; h(π/4) = 50 · 1 = 50 m; h(π/3) = 50√3 ≈ 86.60 m.
  3. (b) (50 − 28.87)/(π/12) ≈ 80.7 m per radian, then (86.60 − 50)/(π/12) ≈ 139.8 m per radian. Equal turns of the camera cover more and more height: h is concave up on (0, π/2).
  4. (c) As θ → π/2, cos θ → 0 and tan θ → ∞. At 80° the rocket is 283.6 m up, at 85° it is 571.5 m. The camera never points straight up: θ = π/2 is a vertical asymptote.

Common mistakes

  • Using period 2π for tangent. It is π (or π/|b| after a squeeze).
  • Putting asymptotes where sin θ = 0. Those are the zeros; the asymptotes are where cos θ = 0.
  • Evaluating tan(π/2) as 0 or 1. It is undefined.
  • Thinking a tangent graph has a maximum. Each branch goes from −∞ to ∞ (or the reverse).
  • Forgetting that the period of a tan(bθ) is π/|b|, not 2π/|b|.

Why the period is π

Sine and cosine come back to the same value only after a full turn, because the point must return to the same place. Tangent only needs the same slope, and the radius at θ + π lies along the same line as the radius at θ (pointing the opposite way). Algebraically, sin(θ + π) = −sin θ and cos(θ + π) = −cos θ, and the two negatives cancel in the ratio.
