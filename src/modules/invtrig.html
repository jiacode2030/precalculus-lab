Inverse trig functions

Ask the question backwards: which angle has this sine? Infinitely many do, so each inverse function agrees to give just one.

The idea

Sine takes an angle and gives a height. The inverse question, "which angle has height 1/2?", has infinitely many answers (π/6, 5π/6, π/6 + 2π, ...). A function must give one output, so we restrict the domain of sine to an interval where it is one-to-one and takes every value once: [−π/2, π/2], the right half of the circle. On that piece, the inverse is arcsin (also written sin⁻¹).

The same idea for the others: cosine is restricted to [0, π] (the top half), giving arccos; tangent to (−π/2, π/2), giving arctan. So arcsin and arctan always answer between −π/2 and π/2, and arccos always answers between 0 and π.

The graph of an inverse is the graph of the restricted function reflected over the line y = x: inputs and outputs trade places. arcsin and arccos take inputs only from [−1, 1] (heights and widths on the unit circle); arctan takes any real number (any slope).

Pick the one the function gives: 11 values

Each inverse gives one angle, from its gold range. Find the direction first, then the angle in the range.

1. arcsin(1/2) = ?

Height 1/2 happens at π/6 and 5π/6, but arcsin only answers on the right half of the circle (−π/2 to π/2). So π/6.

2. arcsin(−√2/2) = ?

7π/4 points the right way, but it is outside [−π/2, π/2]. The same direction inside the allowed range is −π/4.

3. arccos(−1/2) = ?

Width −1/2 happens at 2π/3 and 4π/3. arccos only answers on the top half (0 to π), so 2π/3.

4. arccos(√3/2) = ?

Width √3/2 on the top half is at π/6. (−π/6 has the same width but is on the bottom half.)

5. arctan(−1) = ?

Slope −1 at 3π/4 and at −π/4 (the same line). arctan answers on the right half, open interval (−π/2, π/2): −π/4.

6. arctan(√3) = ?

Slope √3 = sin/cos = (√3/2)/(1/2): the angle π/3. 4π/3 lies on the same line but outside the range.

7. arcsin(−1) = ?

Height −1 is the bottom of the circle. In [−π/2, π/2] that angle is −π/2, not 3π/2.

8. arccos(0) = ?

Width 0 on the top half: straight up, π/2.

9. arccos(−√2/2) = ?

Width −√2/2 on the top half is in quadrant II: 3π/4.

10. arcsin(sin(5π/6)) = ?

sin(5π/6) = 1/2, so this is arcsin(1/2) = π/6. arcsin cannot return 5π/6: it is outside [−π/2, π/2]. "arcsin undoes sin" only on that range.

11. arctan(−√3/3) = ?

Slope −√3/3 = −tan(π/6). In (−π/2, π/2): −π/6.

Try this

Predict what will happen first. Then set it up and check.

  1. With arcsin, set x = 0.87 (it snaps to √3/2). Read the output, then find the matching point on the blue sine graph.

    What you should see

    arcsin(√3/2) = π/3 ≈ 1.047. The blue point (π/3, √3/2) on the sine graph and the green point (√3/2, π/3) on the arcsin graph are mirror images across y = x: input and output trade places.

  2. Tick "Show the whole unrestricted graph". Why can't the whole sine wave be flipped?

    What you should see

    Flipped, the full wave would fail the vertical line test: one x would go to many angles. Only the solid piece on [−π/2, π/2] passes the horizontal line test, so only it has an inverse function.

  3. Switch to arccos and set x = −0.5. Is the answer negative?

    What you should see

    No: arccos(−0.5) = 2π/3 ≈ 2.094. arccos answers on the top half of the circle, [0, π], so its outputs are never negative. A negative input means an angle in quadrant II.

  4. In the second lab choose sin and k = 0.5. How many angles in view have sine 0.5? Which does arcsin pick?

    What you should see

    Four in [−2π, 2π] (−11π/6, −7π/6, π/6, 5π/6), and infinitely many overall. arcsin picks π/6, the one on the gold restricted piece.

  5. Choose tan and push k to 4, then −4. Does arctan ever reach π/2?

    What you should see

    No. arctan 4 ≈ 1.326 and arctan(−4) ≈ −1.326. As k grows the answer creeps toward π/2 ≈ 1.571 but never gets there: y = ±π/2 are horizontal asymptotes of arctan.

Worked example

Evaluate exactly: (a) arccos(−1/2) (b) arcsin(sin(3π/4)) (c) cos(arcsin(3/5)).

Try it yourself first, then reveal one step at a time.

  1. (a) Range first. arccos answers in [0, π], the top half of the circle.
  2. (a) Find the angle. Width −1/2 on the top half is in quadrant II with reference angle π/3: arccos(−1/2) = 2π/3.
  3. (a) Check. cos(2π/3) = −1/2 and 2π/3 is in [0, π]. ✓
  4. (b) sin(3π/4) = √2/2. arcsin(√2/2) must be in [−π/2, π/2], so it is π/4, not 3π/4. The inverse undoes sine only on its restricted range.
  5. (c) Let θ = arcsin(3/5): sin θ = 3/5 with θ in quadrant I. On a 3-4-5 right triangle (or from sin² + cos² = 1), cos θ = √(1 − 9/25) = 4/5, positive because θ is in [−π/2, π/2].

Worked example 2: ladders and ramps

A 6 m ladder leans against a wall with its foot 1.5 m from the wall. (a) Find the angle θ between the ladder and the ground. (b) A wheelchair ramp rises 0.5 m over a horizontal run of 6 m. Find its angle with the ground.

Try it yourself first, then reveal one step at a time.

  1. Set up (a). The ladder is the hypotenuse (6 m) and the distance along the ground is the side adjacent to θ (1.5 m), so cos θ = 1.5/6 = 0.25.
  2. Which inverse? We know a cosine and want the angle, so θ = arccos(0.25). An acute angle is in arccos's range [0, π], so this is the one we want.
  3. (a) Answer. θ = arccos(0.25) ≈ 1.318 rad ≈ 75.5°. This is the "4 to 1" ladder safety rule: the foot one quarter of the ladder's length from the wall.
  4. (b) Rise over run is the tangent: tan θ = 0.5/6 = 1/12, so θ = arctan(1/12) ≈ 0.0831 rad ≈ 4.76°. A 1 : 12 slope is the steepest ramp the US accessibility standards allow.

Common mistakes

  • Answering arcsin(1/2) = 5π/6 or 150°. Both have sine 1/2, but arcsin only returns angles in [−π/2, π/2].
  • Giving a negative answer for arccos. Its range is [0, π].
  • Assuming arcsin(sin θ) = θ always. It is true only when θ is in [−π/2, π/2].
  • Reading sin⁻¹ x as 1/sin x. The −1 means inverse function, not reciprocal; 1/sin x is csc x.
  • Taking arcsin of a number bigger than 1. No angle has sine 1.2: it is not in the domain.

Why these ranges

Each range is chosen to contain the acute angles (so right-triangle problems work directly), to hit every output value exactly once, and to be one connected piece. For sine that is [−π/2, π/2]: from the bottom of the circle up the right side to the top. For cosine it is [0, π], the top half, because the right half would give each width twice.
