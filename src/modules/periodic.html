Periodic phenomena

Tides, heartbeats, seasons and wheels all repeat. Learn one cycle and you know the whole function.

The idea

A function is periodic if its values repeat after a fixed horizontal distance p: f(x + p) = f(x) for every x. The smallest such positive p is the period. One period of the graph is a cycle; copy it end to end and you have the whole graph.

Everything about one cycle repeats: where the function is increasing or decreasing, where it is concave up or down, its maximum and minimum, and its rates of change. So to find f(97) you only need to know where 97 lands inside one cycle: subtract whole periods.

Two more words describe the vertical size: the midline is halfway between the maximum and minimum, (max + min)/2, and the amplitude is the distance from the midline to the maximum, (max − min)/2. Periodic functions do not have to be smooth waves: a heartbeat or a sawtooth is periodic too.

Try this

Predict what will happen first. Then set it up and check.

  1. In the first lab, set x = 1 and slide p from 4 to 2. What stays matched?

    What you should see

    The three orange points always have the same height, one period apart: f(x − p) = f(x) = f(x + p). Changing p squeezes or stretches the cycle, and the copies follow.

  2. Choose Sawtooth, then drag a point in the gold band. Why does every tooth change?

    What you should see

    The whole graph is copies of the one cycle in the gold band. Change the cycle and every copy changes with it.

  3. Choose Pulse with p = 4. On which intervals is the function increasing, for all x?

    What you should see

    Find the increasing pieces inside one cycle, then add 4k. Whatever happens on [0, 4) happens again on [4, 8), [8, 12), and so on.

  4. In the second lab choose Heartbeat. Drag the cursors onto two neighboring tall spikes. What is the period and the heart rate?

    What you should see

    The spikes are 0.8 s apart, so the period is 0.8 s and the rate is 60 ÷ 0.8 = 75 beats per minute.

  5. Choose Mixed tide. Measure from one high tide to the next, then to the one after. Is the period 12.42 hours?

    What you should see

    No. Neighboring high tides have different heights, so the pattern only repeats after two of them: the period is about 24.84 hours. The period is the shortest shift that reproduces the whole graph, not just one feature.

Worked example

The graph shows a periodic function f. Find the period, midline and amplitude, then find f(13), f(10.5) and f(−2.5).

Try it yourself first, then reveal one step at a time.

  1. Period. The pattern on [0, 4) repeats: period 4.
  2. Midline and amplitude. Max 3, min −1: midline (3 + (−1))/2 = 1, amplitude (3 − (−1))/2 = 2.
  3. f(13). 13 = 1 + 3(4), so f(13) = f(1) = 3.
  4. f(10.5). 10.5 = 2.5 + 2(4), so f(10.5) = f(2.5) = −1 (on the flat part).
  5. f(−2.5). Add a period: −2.5 + 4 = 1.5, so f(−2.5) = f(1.5). Halfway down from 3 (at x = 1) to −1 (at x = 2): 1.

Worked example 2: reading a heart monitor

A heart-monitor strip shows the tall spikes (R peaks) at t = 0.2 s and every 0.8 s after that. (a) What is the period? (b) What is the heart rate in beats per minute? (c) When is the 10th R peak?

Try it yourself first, then reveal one step at a time.

  1. The repeating feature. Measure from one R peak to the next; any repeated feature works, but the tall spike is easiest to read.
  2. (a) The peaks are 0.8 s apart, so the period is 0.8 s.
  3. (b) Frequency = 1/period = 1.25 beats per second, so 60 × 1.25 = 75 beats per minute, a normal resting rate.
  4. (c) The first peak is at 0.2 s and each later one adds 0.8 s, so the 10th is at 0.2 + 9(0.8) = 7.4 s.

Common mistakes

  • Measuring the period between a maximum and the next minimum. That is half a period for a symmetric wave.
  • Thinking a periodic function must look like a sine wave.
  • Taking the period from two features that are not the same (a high tide and a slightly lower high tide).
  • Forgetting negative shifts: f(−2.5) = f(−2.5 + 4).
  • Calling (max − min) the amplitude. Amplitude is half of that.

Why periods make predictions easy

Once you know f on one cycle and the period p, every value is known. Write x = r + kp, where r is in the first cycle and k is a whole number; then f(x) = f(r). That is exactly how a calendar works: knowing what day of the week the 1st is tells you every date, because the week has period 7.
