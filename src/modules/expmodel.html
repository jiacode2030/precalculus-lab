Exponential models & data

Build an exponential model from two points or a table, test it against competing models, and say where it should not be trusted.

The idea

To build an exponential model f(x) = a·bˣ from two points (x₁, y₁) and (x₂, y₂): divide the outputs, y₂/y₁ = b^(x₂ − x₁), then take the root, b = (y₂/y₁)^(1/(x₂ − x₁)), and find a from either point. In a table with equally spaced inputs, an exponential model has a constant ratio between consecutive outputs; a linear model has a constant difference.

Real data are noisy, so a model never hits every point. A residual is data minus model. A good model has small residuals with no pattern. When two models both fit the data, compare their residuals, and think about the context: Can this quantity really grow without bound? What is a sensible domain? Models that agree inside the data can disagree wildly outside it, so extrapolation needs care.

Competing models: for the same data you can build a linear, a quadratic and an exponential model. The best one has small, patternless residuals and makes sense in the situation. A quadratic eventually turns around; an exponential never does; a line grows at a fixed rate. Each of these behaviors may or may not fit what you know about the real thing.

Worked example: a model from two points

A town had 12,000 people in 2010 and 15,500 in 2020. Build an exponential model P(t) for t years since 2010 and predict the population in 2030.

Try it yourself first, then reveal one step at a time.

  1. Initial value. P(0) = 12000, so a = 12000.
  2. Growth factor. 12000·b¹⁰ = 15500, so b¹⁰ = 15500/12000 = 1.2917 and b = 1.2917^(1/10) ≈ 1.0259: about 2.6% growth per year.
  3. Model. P(t) = 12000(1.0259)ᵗ.
  4. Predict. 2030 is t = 20: P(20) = 12000(1.2917)² ≈ 20,021 people. This assumes the same growth rate for 10 more years (extrapolation).

Common mistakes

  • Taking a ratio of inputs instead of outputs.
  • Using a line because it fits the data decently without checking the pattern of residuals.
  • Extrapolating far beyond the data as if the model is certain.
  • Rounding b too early: small changes in b become big changes in far predictions.

Interpolation versus extrapolation

Predicting between data points (interpolation) is usually safe when the model fits well. Predicting outside the data (extrapolation) depends on the assumption that the pattern continues. Exponential models are especially fragile: a tiny error in b multiplies over many steps.
