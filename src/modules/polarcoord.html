Polar coordinates

Instead of "over and up", say "how far and which way". A point in the plane can be named by its distance from the origin and its angle.

The idea

In polar coordinates a point is (r, θ): turn to the angle θ (counterclockwise from the positive x-axis), then go a distance r along that ray. It is how radar, sonar and a lighthouse beam describe position.

Converting is the unit circle again, scaled by r: x = r cos θ and y = r sin θ. Going back, r² = x² + y² and tan θ = y/x, but tan θ = y/x has two solutions in each full turn: choose the angle in the quadrant where the point actually is.

One point has many polar names. Adding 2π to θ lands on the same ray. A negative r means "walk backwards": (−r, θ) is the same point as (r, θ + π). A complex number a + bi is the point (a, b), so it has a polar form too: a + bi = r(cos θ + i sin θ).

Try this

Predict what will happen first. Then set it up and check.

  1. Set r = 3 and θ = 135°. Predict (x, y) before you read it.

    What you should see

    x = 3 cos 135° = −3√2/2 ≈ −2.121 and y = 3 sin 135° ≈ 2.121: the point is up and to the left, as quadrant II should be.

  2. Keep r = 3, θ = 135° and tick "negative r". Where does the point go?

    What you should see

    To (2.121, −2.121), on the opposite ray (315°). (−3, 135°) is the same point as (3, 315°): a negative r walks backwards.

  3. Set θ = 30°, then 390° would be... why does the slider stop at 360°?

    What you should see

    Because 390° is the same ray as 30°. Every point has infinitely many polar names: (2, 30°) = (2, 390°) = (2, −330°) = (−2, 210°).

  4. In the complex plane set a = 1, b = 1.7 (about √3). Read r and θ.

    What you should see

    r = √(1 + 1.7²) ≈ 1.97 and θ ≈ 59.5°. With b = √3 exactly it is r = 2, θ = π/3: 1 + i√3 = 2(cos π/3 + i sin π/3).

  5. Set a = −2, b = 0. What is θ, and why is "θ = arctan(b/a)" not enough?

    What you should see

    θ = π (180°). arctan(0/−2) = arctan 0 = 0, which points the wrong way. arctan only returns angles in quadrants I and IV, so a point with a negative real part needs π added.

Worked example

Write the point (−3, 3) in polar coordinates in two different ways.

Try it yourself first, then reveal one step at a time.

  1. Plot it. x = −3, y = 3: quadrant II.
  2. Distance. r = √((−3)² + 3²) = √18 = 3√2 ≈ 4.243.
  3. Angle. tan θ = 3/(−3) = −1. The quadrant II angle with tan θ = −1 is θ = 3π/4. (−π/4 also has tangent −1, but points into quadrant IV.) So the point is (3√2, 3π/4).
  4. A second name. Walk backwards along the opposite ray: (−3√2, 3π/4 − π) = (−3√2, −π/4). Check: x = −3√2 cos(−π/4) = −3 and y = −3√2 sin(−π/4) = 3.

Worked example 2: a plane on the radar screen

An air-traffic radar shows a small plane 12 km from the station at θ = 210°, measured counterclockwise from due east. How far east or west, and how far north or south, is the plane?

Try it yourself first, then reveal one step at a time.

  1. The polar point. r = 12 km, θ = 210° = 7π/6: quadrant III, reference angle 30°.
  2. East–west. x = 12 cos 210° = 12 × (−√3/2) = −6√3 ≈ −10.39 km.
  3. North–south. y = 12 sin 210° = 12 × (−1/2) = −6 km.
  4. Answer. The plane is about 10.4 km west and 6 km south of the station. Check: √(10.39² + 6²) ≈ 12. Note that real navigation measures bearings clockwise from north; this problem uses the math convention.

Common mistakes

  • Using θ = arctan(y/x) without checking the quadrant. For (−3, 3) the calculator gives −π/4, but the point is at 3π/4.
  • Thinking (r, θ) names a point uniquely. (r, θ), (r, θ + 2π) and (−r, θ + π) are all the same point.
  • Swapping sine and cosine: x goes with cos, y with sin.
  • Plotting a negative r on the ray θ. It goes on the opposite ray, θ + π.
  • Mixing degrees and radians within one problem.

Converting equations

The same substitutions turn a polar equation into a rectangular one. For r = 4 cos θ, multiply by r: r² = 4r cos θ, so x² + y² = 4x, which is (x − 2)² + y² = 4: a circle of radius 2 centered at (2, 0). Going the other way, the line y = 3 is r sin θ = 3, or r = 3 csc θ.
