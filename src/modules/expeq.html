Exponential & log equations

To get an unknown out of an exponent, take a logarithm. To get it out of a logarithm, exponentiate. Then check the answer against the domain.

The idea

To solve an exponential equation, isolate the exponential part and take a log of both sides: a·bˣ = c gives bˣ = c/a, so x = log_b(c/a) = ln(c/a) / ln b. If both sides are powers of the same base, simply equate exponents: 2^(3x − 1) = 32 = 2⁵ gives 3x − 1 = 5.

To solve a logarithmic equation, combine logs with the rules into a single log if needed, then rewrite as an exponential: log_b(u) = c ⇔ u = bᶜ. Always check the domain: the input of every log must be positive, and an algebraic solution that breaks this is extraneous. For example log₂ x + log₂(x − 2) = 3 gives x² − 2x − 8 = 0, but only x = 4 works: x = −2 is outside the domain.

Inequalities follow the same path. The key is the direction: applying a logarithm with base b > 1 keeps the inequality direction, but dividing or multiplying by a negative number (like ln 0.88 < 0) reverses it. Always sanity-check with a test value, or read the answer from the graph: where is the curve above or below the line?

Try this

Predict what will happen first. Then set it up and check.

  1. Set a = 3, b = 2, c = 24 and press =. What is x?

    What you should see

    x = 3: 3·2³ = 24. The curve crosses the line at x = 3.

  2. Switch to a·bˣ > c. Which side of x = 3 is the solution?

    What you should see

    x > 3: to the right the exponential is above the line, so its output is bigger than c.

  3. Now slide b below 1, to 0.5, keeping a·bˣ > c. What flips?

    What you should see

    The solution becomes x < something: a decaying exponential is above the line on the left. The log of a base below 1 is negative, which reverses the inequality.

  4. In the second lab with d = 2 and k = 3, which root is a valid solution?

    What you should see

    x = 4 works. The other root, x = −2, would need log₂(−2), which is not a real number, so it is extraneous.

Worked example: when is the car worth less than $10,000?

A car's value is V(t) = 24000(0.88)ᵗ dollars after t years. After how many years is it worth less than $10,000?

Try it yourself first, then reveal one step at a time.

  1. Set up. Solve 24000(0.88)ᵗ < 10000. Divide by 24000: 0.88ᵗ < 10/24 = 0.41667.
  2. Take a logarithm. ln of both sides: t·ln 0.88 < ln 0.41667, that is t(−0.12783) < −0.87547.
  3. Divide by a negative number. Dividing by −0.12783 reverses the inequality: t > 0.87547/0.12783 ≈ 6.85.
  4. Check. V(6.85) ≈ 24000(0.4167) = 10,000 ✓ and V(8) = 24000(0.3596) ≈ $8,630, which is below 10,000 ✓. The car is worth less than $10,000 from about year 6.85 on.

Worked example 2: an extraneous solution

Solve log₂ x + log₂(x − 2) = 3.

Try it yourself first, then reveal one step at a time.

  1. Domain first. Both x > 0 and x − 2 > 0, so x > 2.
  2. Combine. log₂[x(x − 2)] = 3, so x(x − 2) = 2³ = 8.
  3. Solve. x² − 2x − 8 = 0, (x − 4)(x + 2) = 0, so x = 4 or x = −2.
  4. Check the domain. x = −2 is not greater than 2, so it is extraneous. Check x = 4: log₂ 4 + log₂ 2 = 2 + 1 = 3 ✓. The only solution is x = 4.

Common mistakes

  • Writing ln(c/a) / ln b as ln(c/a)/b or ln c − ln a / ln b without parentheses.
  • Forgetting to reverse the inequality when dividing by a negative number (log of a base below 1, or ln of a number below 1).
  • Keeping an answer that makes the inside of a log zero or negative.
  • Taking the log of each term of a sum: log(a + b) is not log a + log b.

Reading a solution from the graph

Solving a·bˣ = c is asking where the graph of the exponential meets the horizontal line y = c. For an inequality, ask where the graph is above or below the line. That picture also explains the flip in direction: when b < 1 the curve falls, so "above the line" is on the left.
