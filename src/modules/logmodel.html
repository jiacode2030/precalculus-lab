Logarithmic models & data

Some quantities grow quickly at first and then slow down. When equal multiples of the input give equal steps in the output, a logarithmic model fits.

The idea

A logarithmic model has the form y = a + b·ln x (or a·log_c x + k). Its signature: multiplying the input by a constant adds a constant to the output. Doubling x always adds b·ln 2 to y. So a table whose inputs form a geometric pattern (1, 2, 4, 8, …) and whose outputs have constant differences is logarithmic.

To build a log model from two points, use the logarithm of the inputs: b = (y₂ − y₁)/(ln x₂ − ln x₁) and a = y₁ − b·ln x₁. To solve for x, undo the log: x = e^((y − a)/b). A log model is the inverse of an exponential model: if y is logarithmic in x, then x is exponential in y.

Interpret with care: a log function climbs without bound, but slowly, and is defined only for x > 0. In real situations other limits appear (a test score cannot exceed 100), so state the domain where the model makes sense. Compare it with linear, quadratic and exponential models using residuals and context, as in the last module.

  1. Pattern. The hours double each time and the score goes up by about the same amount each time (8, 7, 9, 7, 8). Equal multiples of the input give equal steps in the output: choose y = a + b ln x.
  2. Find a. At x = 1, ln 1 = 0, so a = y(1) = 42.
  3. Find b. 81 = 42 + b ln 32, so b = 39/ln 32 = 39/3.4657 ≈ 11.25.
  4. Predict. y(10) = 42 + 11.25 ln 10 = 42 + 11.25(2.3026) ≈ 67.9. This assumes the same trend, and cannot continue past a score of 100.

Worked example 2: altitude from air pressure

A model for altitude (km) in terms of air pressure P (kPa) is h = 38.8 − 8.4 ln P. Find the altitude at P = 50 kPa, and the pressure at an altitude of 10 km.

Try it yourself first, then reveal one step at a time.

  1. Evaluate. h(50) = 38.8 − 8.4 ln 50 = 38.8 − 8.4(3.912) = 38.8 − 32.86 ≈ 5.94 km.
  2. Set up the reverse. 38.8 − 8.4 ln P = 10, so 8.4 ln P = 28.8 and ln P = 3.4286.
  3. Undo the log. P = e^3.4286 ≈ 30.8 kPa.
  4. Check. h(30.8) = 38.8 − 8.4 ln 30.8 = 38.8 − 8.4(3.4279) ≈ 10.0 ✓. Pressure falls by half roughly every 5.8 km.

Common mistakes

  • Using ln x when the inputs are not positive.
  • Forgetting that a is the value at x = 1, not at x = 0 (ln 0 does not exist).
  • Trusting a log model far outside the data: it keeps rising forever, but real quantities hit limits.
  • Solving a·ln x = c by dividing the ln: x = e^(c/a), not (c/a) with ln removed.

Log models are exponential models seen from the other side

If y = a + b ln x, solving for x gives x = e^((y − a)/b), an exponential function of y. When you plot y against ln x you get a straight line, and when you plot ln y against x for an exponential model you also get a straight line. Both are called semi-log plots, and the next module uses them to identify exponential and logarithmic models.
