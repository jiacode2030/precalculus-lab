Equivalent forms

Factored, expanded, divided: the same function can be written many ways, and each way shows something different.

The idea

A polynomial can be written factored, a(x − r₁)(x − r₂)…, or expanded, aₙxⁿ + … + a₀. Factored form shows the zeros and their multiplicities. Expanded form shows the degree, the leading term and the y-intercept a₀. Converting between them means multiplying out or factoring.

To divide polynomials, use long division or, when dividing by (x − r), synthetic division. The result: p(x) = d(x)·q(x) + R(x), where the remainder R has smaller degree than the divisor d. For a divisor (x − r) the remainder is a number, and it equals p(r): the Remainder Theorem. If the remainder is 0, then (x − r) is a factor.

Dividing the whole equation by d(x) gives a rational function as a quotient plus a remainder term: p(x)/d(x) = q(x) + R(x)/d(x). Far from the origin, R/d shrinks to 0, so the rational function follows q(x): for a quotient of degree 1 this is the slanted line (oblique asymptote).

Try this

Predict what will happen first. Then set it up and check.

  1. Set the coefficients to 1, 0, −7, 6 with r = 2. What is the remainder, and what does it tell you?

    What you should see

    The remainder is 0: p(2) = 8 − 14 + 6 = 0, so (x − 2) is a factor. The quotient x² + 2x − 3 factors further as (x + 3)(x − 1).

  2. Change the constant to 7. What is the remainder now, and how does it compare with p(2)?

    What you should see

    The remainder is 1, and p(2) = 1: the Remainder Theorem. The remainder is just the output at r.

  3. Press Next step repeatedly. Which numbers get multiplied by r?

    What you should see

    Each result from the bottom row gets multiplied by r and written under the next coefficient, then added. Bring down, multiply, add, repeat.

  4. In the second lab, set x = 8. How much of f(x) comes from the remainder term?

    What you should see

    Almost none: R/d = 9/7 ≈ 1.29, compared with a quotient value of 12. The farther out you go, the smaller the remainder term and the closer f is to the slanted line.

  5. Move x close to the vertical asymptote. Which part dominates?

    What you should see

    The remainder term R/d: it grows without bound as d → 0, while the quotient stays moderate. Near an asymptote the remainder wins; far away the quotient wins.

Worked example: dividing a volume

A box has volume V(x) = 2x³ + 9x² + 7x − 6 and one dimension (x + 3). Find the other two dimensions.

Try it yourself first, then reveal one step at a time.

  1. Set up. Divide V(x) by (x + 3) = (x − (−3)), so r = −3, with coefficients 2, 9, 7, −6.
  2. Synthetic division. Bring down 2. 2 × (−3) = −6; 9 − 6 = 3. 3 × (−3) = −9; 7 − 9 = −2. (−2) × (−3) = 6; −6 + 6 = 0.
  3. Read it. The quotient is 2x² + 3x − 2 with remainder 0, which confirms that (x + 3) is a factor.
  4. Factor the quotient. 2x² + 3x − 2 = (2x − 1)(x + 2). The dimensions are (x + 3), (2x − 1) and (x + 2).

Worked example 2: cost per ticket

The total cost of making n tickets is n² + 12n + 500 dollars, so the average cost per ticket is A(n) = (n² + 12n + 500)/(n + 4). Rewrite A(n) as a quotient plus remainder and say what happens for large n.

Try it yourself first, then reveal one step at a time.

  1. Divide. (n + 4)(n + 8) = n² + 12n + 32, and 500 − 32 = 468: n² + 12n + 500 = (n + 4)(n + 8) + 468.
  2. Rewrite. A(n) = n + 8 + 468/(n + 4).
  3. Large n. The fraction 468/(n + 4) shrinks toward 0, so A(n) follows the slanted line y = n + 8: no horizontal asymptote, a slanted one.
  4. Check. A(20) = 28 + 468/24 = 28 + 19.5 = 47.5. Directly: (400 + 240 + 500)/24 = 1140/24 = 47.5 ✓.

Common mistakes

  • Forgetting a 0 for a missing term: dividing x³ − 7x + 6 means the coefficients are 1, 0, −7, 6.
  • Using r with the wrong sign: dividing by (x + 3) uses r = −3.
  • Calling the last number the last coefficient of the quotient: it is the remainder.
  • Cancelling terms across a sum in a fraction.

Why the remainder is p(r)

Write p(x) = (x − r)q(x) + R. Put x = r: p(r) = 0·q(r) + R = R. So the remainder is exactly the value of p at r. That makes division a fast way to test whether r is a zero: if the remainder is 0, you have a zero and a factor at the same time.
