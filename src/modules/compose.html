Composition of functions

Feed the output of one function into another. The order matters, and the domain of the composite can be smaller than either piece.

The idea

The composition (f∘g)(x) = f(g(x)) means: apply g first, then f to the result. g is the inner function and f the outer one. Many real chains are compositions: time → radius of a ripple → area of the circle; sticker price → after coupon → after a discount.

Order matters: usually f(g(x)) ≠ g(f(x)). Try f(x) = 2x and g(x) = x + 3: f(g(x)) = 2x + 6 but g(f(x)) = 2x + 3. The domain of f∘g is the set of x in the domain of g for which g(x) lies in the domain of f. For f(x) = √x and g(x) = x − 3 that means x ≥ 3.

You can evaluate a composition from formulas, graphs or tables: go inside first, then read the outer function at that value. And you can decompose a formula: h(x) = (3x + 1)² is f(g(x)) with g(x) = 3x + 1 and f(x) = x². Composition is how inverse functions and many transformations are defined, so Unit 2 uses it constantly.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose g(x) = x − 3 and f(x) = √x. For which x does f(g(x)) exist?

    What you should see

    Only for x ≥ 3: the inner output x − 3 has to be at least 0 before the square root can act on it. Slide x below 3 and the composite disappears.

  2. Keep f = √x but switch g to x². What is the domain now?

    What you should see

    All real numbers: x² is never negative, so √(x²) is always defined. (It equals |x|.)

  3. With g(x) = 2x + 1 and f(x) = 3x − 2 compare the two orders at x = 2.

    What you should see

    f(g(2)) = f(5) = 13 but g(f(2)) = g(4) = 9. The order changes the answer.

  4. In the second lab set x = 2. What is f(g(2)), and why can g(f(2)) not be found?

    What you should see

    g(2) = 1 and f(1) = 6, so f(g(2)) = 6. But f(2) = −1 is not in g's table, so g(f(2)) cannot be read.

Worked example: a growing ripple

A circular ripple spreads so that its radius after t seconds is r(t) = 2t centimeters. The area of a circle of radius r is A(r) = πr². Write the area as a function of t and find the area after 3 seconds.

Try it yourself first, then reveal one step at a time.

  1. Inner and outer. t goes into r first (inner), and the radius goes into A (outer): the area is A(r(t)).
  2. Substitute. A(r(t)) = π(2t)² = π·4t² = 4πt².
  3. Evaluate. At t = 3: 4π(9) = 36π ≈ 113.1 cm².
  4. Check by steps. r(3) = 6 cm, then A(6) = π(36) = 36π ✓.

Worked example 2: coupon, then sale

A store takes 20% off every item: f(p) = 0.8p, and also accepts a $10 coupon: g(p) = p − 10. Find f(g(p)) and g(f(p)), and compare them for an item priced at $60.

Try it yourself first, then reveal one step at a time.

  1. Coupon first. f(g(p)) = 0.8(p − 10) = 0.8p − 8.
  2. Sale first. g(f(p)) = 0.8p − 10.
  3. At p = 60. f(g(60)) = 0.8(50) = $40; g(f(60)) = 48 − 10 = $38.
  4. Conclusion. The two orders differ, so composition is not commutative. Here sale-first is $2 cheaper: the $10 coupon is worth a full $10 at the end, but taken first it is shrunk by the 20% to only $8.

Common mistakes

  • Applying the functions in the wrong order: f(g(x)) means g first.
  • Multiplying instead of composing: f(g(x)) is not f(x)·g(x).
  • Forgetting that the domain of the composite is limited by the inner function and by what the outer function accepts.
  • Assuming f(g(x)) = g(f(x)).

Composition is not multiplication

f(x)·g(x) multiplies outputs of two functions at the same x. f(g(x)) feeds the output of g into f. For f(x) = x² and g(x) = x + 1, the product is x²(x + 1) but the composite is (x + 1)². Every time you substitute an expression for x, you are composing.
