Polar graphs

Give a radius for every angle and a curve draws itself: roses, hearts, loops and spirals, all from one rule r = f(θ).

The idea

A polar function r = f(θ) sweeps a ray around the origin and, at each angle, puts a point at distance f(θ). Sweep θ from 0 to 2π and the points trace a curve. When f(θ) is negative, the point goes on the opposite ray.

The same function has two pictures. In the (θ, r) plane it is an ordinary graph: θ across, r up. In the polar plane it wraps around the origin. Reading one from the other is the key skill: where the rectangular graph crosses zero, the polar curve passes through the origin; where |r| peaks, the polar curve is farthest out.

Families to know: circles r = a, r = a cos θ, r = a sin θ; roses r = a cos(nθ) with n petals if n is odd and 2n if n is even; limaçons r = a + b cos θ (inner loop if |a| < |b|, cardioid if |a| = |b|, dimpled if |b| < |a| < 2|b|, convex if |a| ≥ 2|b|); spirals r = aθ.

Two pictures, one function: 10 curves

Read the left graph (θ across, r up), predict the polar shape, then check.

1. This is the graph of r = 3 cos(2θ) in the (θ, r) plane. What does the polar graph look like?

cos(nθ) with n = 2 (even) gives 2n = 4 petals. On the left graph, r hits ±3 four times per turn: each hump, up or down, is a petal.

2. This is the graph of r = 3 sin(3θ) in the (θ, r) plane. What does the polar graph look like?

n = 3 is odd, so 3 petals. The 6 humps on the left graph come in pairs that land on the same petal: the negative ones retrace the positive ones.

3. This is the graph of r = 2 + 2 cos θ in the (θ, r) plane. What does the polar graph look like?

a = b = 2: r touches 0 once (at θ = π) without going negative. That single touch is the cusp of a cardioid.

4. This is the graph of r = 1 + 2 cos θ in the (θ, r) plane. What does the polar graph look like?

|a| < |b|: r dips below 0 between 2π/3 and 4π/3. Negative r is drawn on the opposite ray, which makes the small inner loop.

5. This is the graph of r = 3 + cos θ in the (θ, r) plane. What does the polar graph look like?

r stays between 2 and 4, never near 0, and a ≥ 2b (3 ≥ 2), so the curve is convex: an egg shape, no dimple.

6. This is the graph of r = 3 + 2 sin θ in the (θ, r) plane. What does the polar graph look like?

b < a < 2b (2 < 3 < 4): r gets fairly small (1 at θ = 3π/2) but not 0, so the bottom caves in: a dimple. Sine makes it point up and down.

7. This is the graph of r = 4 cos θ in the (θ, r) plane. What does the polar graph look like?

r = a cos θ is a circle of diameter 4 through the origin: x² + y² = 4x. Between π/2 and 3π/2, r < 0 retraces the same circle.

8. This is the graph of r = 3 in the (θ, r) plane. What does the polar graph look like?

r is the same at every angle: every point is 3 from the origin.

9. This is the graph of r = θ/2 in the (θ, r) plane. What does the polar graph look like?

r keeps growing with θ, so the curve winds outward: an Archimedean spiral. (On the left graph r is a straight line.)

10. This is the graph of r = 2 sin(4θ) in the (θ, r) plane. What does the polar graph look like?

n = 4 is even: 2n = 8 petals.

Try this

Predict what will happen first. Then set it up and check.

  1. Choose Rose with n = 3, press Play. How many petals, and how many times does the left graph reach ±a?

    What you should see

    Three petals, but the left graph peaks six times (three up, three down). For odd n, the negative-r humps retrace the same petals; that is why odd n gives n petals and even n gives 2n.

  2. Rose with n = 2: count the petals now.

    What you should see

    Four petals. With n even, the negative humps land on new petals between the positive ones.

  3. Choose Limaçon a + b cos θ. Set a = 1, b = 2, then a = 2, b = 2, then a = 3, b = 2. Name each shape.

    What you should see

    a = 1: inner loop (r goes negative). a = 2: cardioid (r touches 0 once, a cusp). a = 3: dimpled limaçon (r never reaches 0, but dips to 1).

  4. Limaçon, a = 1, b = 2. Sweep θ slowly from 100° to 260° (about 1.75 to 4.5). Where is the point drawn while r is negative?

    What you should see

    On the opposite ray: at θ = π, r = −1 and the point is at (1, 0), on the right. That piece is the inner loop, drawn in magenta.

  5. In the second lab choose Circle, then drag one dot down below the θ-axis. What happens on the right?

    What you should see

    The curve dives through the origin and the point for that angle appears on the opposite side. Every zero crossing on the left is a pass through the origin on the right.

Worked example

Sketch r = 2 + 4 cos θ for 0 ≤ θ ≤ 2π. Where does it pass through the origin, and what is the inner loop?

Try it yourself first, then reveal one step at a time.

  1. Table of key angles. θ = 0, π/3, π/2, 2π/3, π give r = 6, 4, 2, 0, −2.
  2. Zeros. 2 + 4 cos θ = 0 when cos θ = −1/2: θ = 2π/3 and 4π/3. The curve passes through the origin at both angles.
  3. Negative r. For 2π/3 < θ < 4π/3, r < 0, so those points go on the opposite ray. At θ = π, r = −2 is plotted at (2, 0): this stretch makes the inner loop.
  4. Symmetry and shape. cos(−θ) = cos θ, so the curve is symmetric about the x-axis. |a| = 2 < |b| = 4: a limaçon with an inner loop, reaching out to (6, 0).

Worked example 2: a microphone's pickup pattern

A cardioid microphone picks up sound with relative sensitivity r = 1 + cos θ, where θ is the angle from the direction the microphone points. (a) Compare its sensitivity at the front, the side (θ = π/2) and the back. (b) At what angle is it 1.5, three-quarters of its maximum?

Try it yourself first, then reveal one step at a time.

  1. Front. θ = 0: r = 1 + 1 = 2, the maximum.
  2. Side. θ = π/2: r = 1 + 0 = 1, half the front value. Half the amplitude is 20 log₁₀(0.5) ≈ −6 dB, the "−6 dB at the side" printed on microphone spec sheets.
  3. Back. θ = π: r = 1 − 1 = 0. It hears nothing from directly behind, which is why singers point it at their mouth and away from the speakers.
  4. (b) 1 + cos θ = 1.5 gives cos θ = 0.5, so θ = π/3 (60°) on either side of the front.

Common mistakes

  • Plotting a negative r on the ray θ itself instead of the opposite ray.
  • Counting petals of r = a cos(nθ) as n for every n: it is 2n when n is even.
  • Stopping at θ = π. Many curves need the full 0 to 2π (a rose with even n, any limaçon).
  • Reading the (θ, r) graph as if it were the shape. It is a different picture of the same function.
  • Assuming every limaçon has a loop: only |a| < |b| does.

Reading the (θ, r) graph

AP questions often show r = f(θ) on rectangular axes and ask about the polar curve. Three translations do most of the work: r = 0 on the graph means the curve is at the origin; |r| largest means the curve is farthest out; r negative means the point is on the opposite side of the origin from the angle θ.
