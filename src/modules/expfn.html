Exponential functions

Linear functions add the same amount each step; exponential functions multiply by the same factor. That one difference changes the whole shape of the graph.

The idea

Over equal-length input intervals, a linear function changes by a constant amount and an exponential function changes by a constant factor. A function of the form f(x) = a·bˣ (a ≠ 0, b > 0, b ≠ 1) is exponential: a is the initial value f(0), the y-intercept, and b is the growth factor, the number you multiply by for each step of 1 in x.

If b > 1 the function is growth: with a > 0 it increases and is concave up; b = 1 + r where r is the percent increase per step. If 0 < b < 1 it is decay: with a > 0 it decreases, still concave up, and r = b − 1 is negative. A 15% growth rate means b = 1.15; a 12% loss means b = 0.88.

The graph has a horizontal asymptote at y = 0. For a > 0, b > 1: as x → ∞ the outputs grow without bound, and as x → −∞ they approach 0. For 0 < b < 1 the two ends swap. The domain is all real numbers; the range is y > 0 (or y < 0 if a < 0). Exponential growth eventually beats any polynomial.

Read the formula from the graph

The y-intercept is a. One step right multiplies by b.

The y-intercept is a = 3 and each step right multiplies by b = f(1)/f(0) = 6/3 = 2. So the function is 3(2)ˣ. The factor is above 1, so it grows.

Try this

Predict what will happen first. Then set it up and check.

  1. Set a = 2 and b = 1.5. Where does the graph cross the y-axis, and what happens each time x goes up by 1?

    What you should see

    It crosses at y = 2 = a. Each step right multiplies the height by 1.5, shown by the dashed arrows.

  2. Slide b below 1. What kind of change is it?

    What you should see

    Decay: the graph falls toward the x-axis but never touches it. The x-axis is the horizontal asymptote, and the graph is still concave up.

  3. Set a = −2 with b = 1.5. What changes?

    What you should see

    The whole graph flips under the x-axis: the range is now y < 0. Still an asymptote at y = 0, but decreasing and concave down.

  4. In the second lab set b = 1.5 and step length 1. Compare the line and the curve at x = 6.

    What you should see

    The line adds 1 each step (it reaches 8) while the curve multiplies by 1.5 (it reaches about 22.8). Same start, same first step, very different futures.

  5. Make b = 1.1 and look at x = 6. Is the exponential far ahead of the line yet?

    What you should see

    Not by much: about 3.54 against 3.2. But the exponential is above the line for every x > 1 and the gap keeps widening, so give it time and it leaves the line far behind.

Worked example: bacteria

A colony starts with 800 bacteria and grows 15% each hour. Write a model for the number f(t) of bacteria after t hours, and estimate the number after 6 hours.

Try it yourself first, then reveal one step at a time.

  1. Growth factor. A 15% increase each hour multiplies the count by b = 1 + 0.15 = 1.15.
  2. Model. The initial value is 800, so f(t) = 800(1.15)ᵗ.
  3. Check one step. f(1) = 800(1.15) = 920, which is 15% more than 800 ✓.
  4. Evaluate. f(6) = 800(1.15)⁶ = 800(2.3131…) ≈ 1850 bacteria.

Worked example 2: a car loses value

A car costs $24,000 and loses 12% of its value each year. Model its value V(t) after t years and find the first whole year when it is worth less than $10,000.

Try it yourself first, then reveal one step at a time.

  1. Decay factor. Losing 12% leaves 88%, so b = 1 − 0.12 = 0.88.
  2. Model. V(t) = 24000(0.88)ᵗ.
  3. Try years. V(6) = 24000(0.4644) ≈ $11,146, still above 10,000. V(7) = 24000(0.4087) ≈ $9,808.
  4. Answer. The first whole year below $10,000 is year 7. (A logarithm will solve 24000(0.88)ᵗ = 10000 exactly: t ≈ 6.85.)

Common mistakes

  • Writing b = 0.12 for a 12% decrease. The factor is 1 − 0.12 = 0.88.
  • Treating the exponential as if it adds a constant each step.
  • Thinking a decay graph crosses the x-axis. It approaches y = 0 but never reaches it.
  • Mixing up a (the starting value) with b (the factor).

Exponential functions at a glance

Equal steps in x give equal ratios in y: f(x + h)/f(x) = bʰ for every x. This is why constant percent change is exponential, and why a table with a constant ratio between outputs, when the inputs go up by equal steps, signals an exponential model.
