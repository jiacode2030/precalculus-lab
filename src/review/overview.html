New to this? Start here

You should be comfortable with Algebra 2: linear and quadratic functions, factoring, and right-triangle trig. Everything else is built here, one idea at a time.

How to use a module

  1. Read The idea: the concept in everyday words.
  2. Play with the graph. Drag the points and move the sliders; the numbers underneath update as you go.
  3. Do Try this: guess first, then press Set it up for me and check.
  4. Work the Worked example one step at a time.
  5. Answer Check yourself, then do the practice problems.

Look for dotted words: tap them for a quick definition. Every simulation has a Coach that explains whatever control you just moved, and a Reset button.

Four ideas you'll use everywhere

  • Watch how the output changes as the input changes. Adding the same amount is linear, multiplying by the same factor is exponential, repeating is periodic.
  • Rate of change is a slope. The average rate of change between two points is the slope of the line through them.
  • Every function has a family. a·f(b(x − h)) + k stretches and shifts any graph the same way.
  • Inverses undo. Logs undo exponentials, arcsin undoes sin, and the graphs are mirror images across y = x.
