Angles and the unit circle

radians = degrees × π/180
180° = π
arc length s = rθ
θ in radians
point = (cos θ, sin θ)
on the unit circle
tan θ = sin θ / cos θ
slope of the terminal ray
sin²θ + cos²θ = 1
the point is on the circle

Special angles (quadrant I)

θ = 0, π/6, π/4, π/3, π/2
sin θ = 0, 1/2, √2/2, √3/2, 1
cos θ = 1, √3/2, √2/2, 1/2, 0
tan θ = 0, √3/3, 1, √3, undefined

Sinusoids

f(θ) = a sin(b(θ + c)) + d
same for cos
amplitude |a| · period 2π/|b| · midline y = d
phase shift −c
shift left by c when c > 0
tan: period π/|b|
vertical asymptotes where cos = 0

Reciprocals and inverses

sec θ = 1/cos θ · csc θ = 1/sin θ · cot θ = cos θ/sin θ
arcsin: [−1, 1] → [−π/2, π/2]
restricted range
arccos: [−1, 1] → [0, π]
arctan: ℝ → (−π/2, π/2)

Identities

1 + tan²θ = sec²θ · 1 + cot²θ = csc²θ
Pythagorean
sin(α ± β) = sin α cos β ± cos α sin β
sum and difference
cos(α ± β) = cos α cos β ∓ sin α sin β
sin 2θ = 2 sin θ cos θ
double angle
cos 2θ = cos²θ − sin²θ = 2cos²θ − 1 = 1 − 2sin²θ

Polar

x = r cos θ · y = r sin θ
polar to rectangular
r² = x² + y² · tan θ = y/x
rectangular to polar (pick θ in the right quadrant)
r > 0 and increasing ⇒ moving away from the origin
r < 0 and decreasing ⇒ also moving away
r = a cos(nθ) or a sin(nθ)
rose: n petals if n odd, 2n if even
r = a + b cos θ
limaçon: inner loop if |a| < |b|, cardioid if |a| = |b|
z = a + bi = r(cos θ + i sin θ)
complex number in polar form
